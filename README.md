# 505 Shareholders

An independent, static shareholder-information site for the September 23, 2026 Board of Directors election at East River House, 505 East 79th Street.

The public site explains the shareholder-supported slate, presents a six-point operating agenda, summarizes the April survey and May straw poll, and provides the relevant public campaign documents. Private chats, resident contact information, bylaws, the proprietary lease, and the outdated June proxy are intentionally excluded.

## Run locally

```text
npm install
npm run dev
```

## Build and verify

```text
npm test
```

The static GitHub Pages output is written to `docs/`.
