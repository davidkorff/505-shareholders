# 505 Shareholders

An independent, static shareholder-information site for the September 23, 2026 Board of Directors election at East River House, 505 East 79th Street.

The public site explains the shareholder-supported slate, presents an eight-priority survey-driven platform, summarizes the April survey and May straw poll, and provides the relevant public campaign documents. The campaign proxy is posted with its original June 18 date clearly disclosed and a request to contact the organizers before signing. Private chats, resident contact information, bylaws, and the proprietary lease are intentionally excluded.

## Run locally

```text
npm install
npm run dev
```

## Build and verify

```text
npm test
```

The static GitHub Pages output is written to `docs/`.
